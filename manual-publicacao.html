Manual de Publicação

Guia completo para gerar e publicar novas versões do app nas lojas

Android (Play Store)  ·  iOS (App Store)
Pré-requisitos
  • Android Studio instalado
  • Xcode instalado (App Store, ~8GB)
  • Conta Google Play Console
  • Apple Developer Program ativo
  • Keystore Android (arquivo .jks)
  • Certificado "Apple Distribution" no Keychain
Etapa 1 — Atualizar e sincronizar o código
Sempre que fizer alterações nos arquivos HTML/JS/CSS, execute estes passos antes de gerar o build.
  1. Copie os arquivos atualizados para a pasta www/

    A pasta www/ é o que o Capacitor empacota no app. Certifique-se que todas as alterações estão lá.

  2. Execute o Capacitor Sync

    No terminal, dentro da pasta do projeto:

    • export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh"
    • npx cap sync android
    • npx cap sync ios

    Isso copia os arquivos web para os projetos nativos Android e iOS.

  3. Incremente a versão do app

    A cada nova versão publicada, atualize obrigatoriamente os dois arquivos abaixo:

    ArquivoCampoExemplo
    android/app/build.gradleversionCode / versionName4 / "1.2"
    ios/App/App.xcodeproj/project.pbxprojCURRENT_PROJECT_VERSION / MARKETING_VERSION4 / 1.2
Importante: o versionCode no Android e o CURRENT_PROJECT_VERSION no iOS devem ser sempre maiores que a versão anterior. As lojas rejeitam builds com número igual ou menor.

Android

Play Store

Gerar AAB assinado e publicar no Google Play Console

Parte A — Gerar o AAB assinado no Android Studio
  1. Abra o projeto Android

    No Android Studio: File → Open → selecione a pasta android/ do projeto

  2. Acesse o menu de build assinado

    Build → Generate Signed Bundle / APK

  3. Selecione "Android App Bundle"

    O formato AAB (.aab) é obrigatório para novas publicações na Play Store. Clique em Next.

  4. Informe o Keystore
    • Clique em Choose existing... e selecione o arquivo .jks ou .keystore
    • Preencha a Key store password
    • Selecione o Key alias e preencha a Key password
    • Clique em Next
  5. Selecione "release" e finalize

    Marque release como Build Variant e clique em Finish.

    Tempo estimado: 2 a 15 minutos. Uma notificação aparece ao concluir.

  6. Localize o arquivo gerado

    Clique em "locate" na notificação ou navegue até: android/app/release/app-release.aab

Parte B — Publicar no Google Play Console
  1. Acesse o Play Console

    Abra play.google.com/console e selecione o app Vitta Sistemas

  2. Crie uma nova versão

    No menu lateral: Produção → Criar nova versão

  3. Faça upload do AAB

    Clique em Adicionar e selecione o arquivo app-release.aab gerado

  4. Preencha as novidades

    No campo "O que há de novo" descreva as alterações desta versão (ex: "Tela de perfil do usuário e melhorias gerais")

  5. Envie para revisão

    Clique em Salvar → Revisar versão → Iniciar lançamento para Produção

    A revisão leva em geral algumas horas a 1 dia útil.

iOS

App Store

Gerar Archive e publicar no App Store Connect

Parte A — Gerar o Archive no Xcode
  1. Abra o projeto iOS

    Abra o arquivo ios/App/App.xcworkspace no Xcode (use sempre o .xcworkspace, nunca o .xcodeproj)

  2. Verifique a assinatura

    Selecione o target App → aba Signing & Capabilities → confirme que o Team está selecionado com sua conta Apple Developer

  3. Selecione o device correto

    No seletor de destino (canto superior), selecione Any iOS Device (arm64) — nunca um simulador

  4. Gere o Archive

    Menu Product → Archive. Aguarde a compilação (2–10 minutos). O Organizer abrirá automaticamente ao terminar.

  5. Distribua o Archive
    • No Organizer, selecione o build recém-criado
    • Clique em Distribute App
    • Selecione App Store Connect → Upload
    • Mantenha todas as opções padrão e clique em Upload
Erro "PLA Update": acesse developer.apple.com/account, aceite o novo contrato de licença e aguarde 10 minutos antes de tentar novamente.
Erro "No signing certificate": no Xcode vá em Settings → Accounts → Manage Certificates → + → Apple Distribution para criar o certificado.
Parte B — Publicar no App Store Connect
  1. Acesse o App Store Connect

    Abra appstoreconnect.apple.com → Meus Apps → selecione Vitta Sistemas

  2. Crie uma nova versão

    Clique em + Versão ou Plataforma → iOS, digite o número da versão (ex: 1.2) e clique em Criar

  3. Preencha "O que há de novo"

    Descreva as alterações desta versão para os usuários

  4. Adicione o Build

    Role até a seção Build → clique em + → selecione o build enviado pelo Xcode

    Caso não apareça, aguarde 5–15 minutos para processar e recarregue a página

  5. Envie para revisão

    Clique em Adicionar para Revisão → Enviar para a App Store

    A Apple leva em média 1 a 3 dias úteis para revisar.
